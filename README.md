# UMFNet

PyTorch implementation of UMFNet.

## Files

- `model/`: network implementation
- `losses.py`: loss functions
- `requirements.txt`: dependencies

## Pretrained weights

Download [umfnet_whu.pth](https://github.com/Saki1220/UMFNet/releases/download/v1.0.0/umfnet_whu.pth).

Checkpoint configuration: `n_classes=7`, `opt_dim=4`, `sar_dim=1` (8 output classes).
